# アンケート図表室

Windows・Macで使える、ローカル専用のアンケート集計アプリです。Box Drive等のパスからExcelを読み込み、設問単独・属性別・クロス集計の図をPNG/SVG/PDFで出力します。

## セットアップと起動

Python 3.11以上を用意してください。初回セットアップにはライブラリを取得できるネットワーク接続が必要です。以後の集計に外部サービスは使用しません。Box Driveのファイル取得にはBoxへの接続が必要な場合があります。

- Windows：`setup_windows.cmd` を実行し、完了後に `start_windows.cmd` を開きます。PythonをPATHに登録してください。
- Mac：ターミナルでアプリのフォルダに移動し、`bash setup_mac.command`、続いて `bash start_mac.command` を実行します。Finderから起動する場合は初回に `chmod +x setup_mac.command start_mac.command` を実行してください。
- 起動後はブラウザの `http://127.0.0.1:8501` で操作します。終了は起動したターミナルで `Ctrl+C`。別PCへのサーバー公開は行いません。

同等の手動手順は `python -m venv .venv` → 仮想環境内のPythonで `-m pip install -r requirements.txt` → `-m streamlit run app.py` です。Macでは作成に `python3` を使用します。

## 操作

1. 左側に設問定義と実データの**ファイルパス**、必要なパスワードを入力して読み込みます。BoxのURLは使用しません。実データをアプリのフォルダへコピーする必要はありません。
2. 対象シートを選び、「データ確認」で設問対応・未認識の回答値を確認します。添付の `sample.xlsx` は2行ヘッダーのみで回答行がありません。
3. 「図を作成」で設問・属性・クロス集計・フィルターを指定します。配色、フォント、寸法、ラベルを調整し、PNG/SVG/PDFを保存できます。
4. 「この図を一覧に追加」で複数図を登録します。一覧の「編集」で設定を作成画面へ呼び出し、変更後に「一覧のこの図を更新」を押すと元の図を更新できます。「この図を一覧に追加」なら別の図として登録します。
5. 「図の一覧・設定」で順番を調整し、ZIPまたは複数ページPDFを出力します。図の条件はJSONで保存・再読込できます。別PCで設定フォントがない場合は同じフォントをインストールしてください。

## 入力と集計ルール

- 回答Excelは1行目に `No.1：設問文`、2行目に複数選択の `1-選択肢名`、3行目以降に1人1行で回答を配置します。単一回答は定義の選択肢名、複数回答は選択時に `〇`（`○` も可）・非選択時に空欄です。複数選択の選択肢名は回答セルではなく2行目から取得します。従来の選択肢名が入る回答形式にも対応し、「その他」列の自由記述はその選択肢を選んだものとして扱います。
- `.xlsx` と `.xlsm` に対応します。`.xlsm` のマクロは実行せず、セルの値だけを読み込みます。拡張子の変更や元ファイルの保存は不要です。
- 1行目の設問文は各複数選択列にも必要です。数値フラグや数値コードは自動で推定せず、未認識の値として確認します。数値入力設問は0以上の整数を扱います。全セルが空の回答行は除外します。
- 定義ファイルの見出し・小問番号0の親項目を除いて対応付けます。添付ファイルの128設問・348列に対応しています。同名小問は親設問と順序で区別します。解決できない対応付けや未知の回答値のある設問は、確認するまで集計できません。
- 割合は標準で有効回答者数が分母です。複数選択は1つ以上選んだ人を有効回答者とし、同じ人の同じ選択肢は1回だけ数えます。合計は100％を超え得ます。
- 無回答と分岐による対象外は空欄だけでは区別できません。「無回答をカテゴリーに含める」場合はそのカテゴリーも有効回答として数えます。「回答しない」「受講したことがない」等は定義された通常の選択肢です。
- 属性が複数選択の場合、同じ回答者が複数グループに所属します。グループ合計は全体の人数と一致しない場合があります。クロス集計も回答者ごとに選択肢ペアの共起を数えます。
- フィルターは条件間AND、同じ条件内の選択肢はORです。対象人数・分母・条件を図注に表示します。分母0の割合は未定義（表では空値、図の値ラベルでは「—」）です。
- 100％積み上げ棒は単一選択の行割合だけに使用します。分母が対象者全員の場合は、無回答も表示する必要があります。
- 数値回答は単独ヒストグラムと基本統計、自由記述は形式認識までを対象とします。統計検定・自由記述の自動分析は含みません。

## デザインと出力

PNGは標準300dpi。幅・高さは図の基本寸法で、切れを防ぐため図注・凡例を含む領域まで出力します。長いラベルや多数のカテゴリーでは寸法・文字サイズ・折り返しを調整してください。SVGは標準で文字をパス化し、PDFはTrueTypeフォントを埋め込みます。SVGの文字を残す場合は閲覧先にも同じフォントが必要です。

棒グラフは標準で高さを自動調整します。指定した高さを最小値とし、カテゴリー数・グループ数と実際の文字の高さから、最大60cmまで広げます。手動で寸法を固定したい場合は「棒グラフの高さを自動調整」を解除してください。「値ラベルの文字サイズ」は軸・凡例の文字サイズと別に変更できます。グループ数が多く60cmでも収まらない場合は、値ラベルを小さくする・非表示にする、またはヒートマップを選択してください。

画面プレビューは最大120dpiで生成し、ダウンロードは指定したdpiを使用します。PNGは図注・凡例込みで4,000万ピクセル／1辺16,000ピクセルを上限とし、超える場合はdpiや寸法の調整を案内します。その場合もプレビューとSVG/PDF出力は利用できます。

Windowsではメイリオ、Macではヒラギノを優先します。表示先のOSにインストールされた日本語フォントを選んでください。設定JSONは設問構造が一致するデータで再利用でき、回答人数や回答内容の変化には影響されません。

## データの扱い

元Excelに書き込みません。復号済みExcel・回答・集計結果の永続キャッシュを作りません。パスワードは読み込み後に入力欄から消去します。回答はセッションのメモリに保持し、再読込・シート変更・クリア・プロセス終了でアプリ内の参照を破棄します。これはOSのスワップ領域やメモリ消去を制御する保証ではありません。

設定JSONには図の条件・表示ラベル・設問と列の対応付けだけを含め、実データのパス・パスワード・個々の回答値の補正は含めません。指定したフィルター選択肢と出力図には集計条件・集計結果が含まれるため、保存先は利用する組織の方針に合わせて選んでください。

Boxによる元ファイルのオンデマンド取得・ローカルキャッシュはBox Drive側の動作です。アプリの保存先としてBoxを使いたい場合は、ブラウザのダウンロード設定で保存先を選択する方式にしてください。

## 検証

`python -m unittest discover -s tests -v` で、添付ファイルの対応付け、合成回答による集計・分母・フィルター、図の出力と設定の検証を実行できます。依存関係が揃った環境では暗号化Excelの往復検証も行います。

Windows環境で、複数選択の「〇」「○」形式を含む28件のテストを確認しました。通常Excelはopenpyxl経由と標準ライブラリの代替読み込みの両方を確認し、画面操作、日本語の図出力、集計・フィルター、設定保存、合成データの暗号化Excelの復号も検証しています。描画キャンバスの不一致、高さ60cmでの出力、60本の棒の値ラベルの配置、過大なPNGの制限とSVG/PDF出力も確認しています。ローカルサーバーのHTTP応答も確認済みです。Mac実機での起動とBox上の実データでの集計は未確認です。
